# 双重检查锁（Double-Checked Locking，DCL）单例模式
```Java
public class SingleTon {

    // volatile 保证可见性，并禁止创建对象过程发生指令重排序
    private static volatile SingleTon instance;

    // 私有构造方法，外部不能直接 new
    private SingleTon() {
    }

    public static SingleTon getInstance() {

        // 第一次检查：对象已经创建时，直接返回，不需要加锁
        if (instance == null) {

            synchronized (SingleTon.class) {

                // 第二次检查：防止多个等待锁的线程重复创建对象
                if (instance == null) {
                    instance = new SingleTon();
                }
            }
        }

        return instance;
    }
}
```

```markdown
synchronized
    │
    └── 解决“多个线程同时创建”的问题

volatile
    │
    ├── 解决“线程看不到最新 instance”的问题
    │
    └── 解决“拿到未初始化完整对象”的问题
```
