# WebSocket 与 TTS 包类关系（文字版）

## 统一箭头规则

- `A → B`：A 持有、调用或依赖 B，箭头指向被使用方 B。
- `A ⇢ B`：A 创建 B，虚线箭头指向被创建方 B。
- `A --|> B`：A 继承 B，空心三角指向父类 B。
- `A ..|> B`：A 实现 B，虚线空心三角指向接口 B。

## WebSocket 包

### 类职责

- `WebSocketTaskExecutor`：任务入口，协调连接池、启动连接任务并创建任务会话。
- `WebSocketExecutor`：按 `modelId` 管理连接池，借出连接并创建租约。
- `WebSocketConnectionLease`：包装一次连接借用，负责归还或失效连接。
- `WebSocketTaskSession`：控制单任务的发送、完成、取消与资源释放。
- `VoiceConnection`：维护真实 WebSocket、当前任务和连接状态机。
- `VoiceConnectionState`：定义连接生命周期的 8 个状态。
- `VoiceStreamCallback`：接收数据包以及完成、异常终态。

### 图中关系

- `WebSocketTaskExecutor → WebSocketExecutor`：持有连接池执行器。
- `WebSocketTaskExecutor ⇢ WebSocketTaskSession`：`openTask()` 创建任务会话。
- `WebSocketExecutor ⇢ WebSocketConnectionLease`：`acquire()` 创建并返回租约。
- `WebSocketTaskSession → WebSocketConnectionLease`：持有租约并在任务结束时关闭。
- `WebSocketTaskSession → VoiceConnection`：调用 `send/finishTask/cancelTask` 控制任务。
- `WebSocketConnectionLease → VoiceConnection`：包装本次借用的物理连接。
- `VoiceConnection → VoiceConnectionState`：保存并迁移连接状态。
- `VoiceConnection → VoiceStreamCallback`：推送数据包和任务终态。

## TTS 包

### 类职责

- `TtsService`：业务层语音合成接口。
- `RoutingTtsService`：选择候选模型和 `TtsClient`，负责首音频确认前的 fallback。
- `TtsClient`：统一厂商 TTS 客户端接口。
- `AbstractWebSocketTtsClient`：复用 WebSocket 包完成开任务、分段发送和回调转换。
- `BaiLianTtsClient`：适配百炼 CosyVoice 协议并输出 MP3 二进制字节。
- `TtsCallback`：接收音频数据及任务终态。
- `BinaryProbeStreamBridge`：探测并缓存首音频前的候选回调，支持 `commit/discard`。
- `TtsTaskObserver`：绑定取消句柄并检查任务是否取消。

### 图中关系

- `RoutingTtsService ..|> TtsService`：实现业务服务接口。
- `AbstractWebSocketTtsClient ..|> TtsClient`：实现厂商客户端接口。
- `BinaryProbeStreamBridge ..|> TtsCallback`：实现音频回调接口。
- `BaiLianTtsClient --|> AbstractWebSocketTtsClient`：继承通用 WebSocket TTS 模板。
- `RoutingTtsService ⇢ BinaryProbeStreamBridge`：每个候选尝试都会创建探测桥。
- `RoutingTtsService → TtsTaskObserver`：绑定取消句柄并读取取消状态。

### 在类框中表达的类型依赖

为减少交叉线，以下关系写在字段或方法中，不再重复画箭头：

- `RoutingTtsService` 持有 `Map<String, TtsClient> clientsByProvider`。
- `BinaryProbeStreamBridge` 持有 `TtsCallback downstream`。
- `AbstractWebSocketTtsClient.synthesize(...)` 接收 `TtsCallback`。
