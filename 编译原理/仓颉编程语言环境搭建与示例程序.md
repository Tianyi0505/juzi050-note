## 一、环境搭建

### 1. 下载 SDK

从仓颉编程语言官网下载中心（`cangjie-lang.cn/download`）获取 Windows x64 版本。官网提供 LTS（1.0.5）、STS（1.2.0）与 Nightly 三个通道，本次实际可用的是 Nightly 通道的 1.3.0-alpha 版本。

| 版本通道 | 安装包 | 大小 | 本机结果 |
| --- | --- | --- | --- |
| LTS 1.0.5 | `cangjie-sdk-windows-x64-1.0.5.zip` | 284 MB | 编译通过，运行崩溃 |
| STS 1.2.0 | `cangjie-sdk-windows-x64-1.2.0.zip` | 251 MB | 编译通过，运行崩溃 |
| Nightly 1.3.0-alpha.20261025001053 | `cangjie-sdk-windows-x64-1.3.0-alpha.20261025001053.zip` | 260 MB | ✅ 编译运行均正常 |

### 2. 解压与环境变量

SDK 为免安装压缩包，解压后即为完整工具链，无需管理员权限。

```powershell
# 解压到 D:\CangjieN（压缩包内层目录名为 cangjie）
7z x cangjie-sdk-windows-x64-1.3.0-alpha.20261025001053.zip -oD:\CangjieN
```

关键目录与环境变量：

| 路径 | 作用 |
| --- | --- |
| `D:\CangjieN\cangjie` | `CANGJIE_HOME`，SDK 根目录 |
| `%CANGJIE_HOME%\bin` | `cjc` 编译器、`cjc-frontend` 前端 |
| `%CANGJIE_HOME%\runtime\lib\windows_x86_64_cjnative` | 运行时动态库（`libcangjie-runtime.dll`、`libcangjie-std-*.dll`） |
| `%CANGJIE_HOME%\tools\bin` | `cjpm` 包管理、`cjdb` 调试器、`cjcov` 覆盖率等 |

SDK 自带 `envsetup.bat` / `envsetup.ps1` / `envsetup.sh`，执行即可一次性配好 `CANGJIE_HOME` 与 `PATH`：

```powershell
D:\CangjieN\cangjie\envsetup.ps1
```

### 4. 踩坑记录

1. **STS/LTS 版本运行期崩溃**：1.2.0 与 1.0.5 两个正式版在本机（Windows 11 Build 26200）上 `cjc` 编译均成功，但生成的 exe 一启动就以 `0xC0000005`（访问冲突）退出，连 `println` 都没执行到，`cjpm init` 也同症状。换用 Nightly 1.3.0-alpha 后一切正常，判断是运行时不兼容该版本 Windows，而非代码或环境变量问题。
2. **`main` 不能加 `func`**：仓颉的入口函数是特殊语法 `main(): Int64 { ... }`，写成 `func main()` 会报错 `'main' declaration doesn't need 'func' keyword`。
3. **控制台编码**：仓颉源文件与字符串按 UTF-8 处理，输出中文前需要 `chcp 65001`，否则 GBK 代码页下中文乱码。

## 二、示例程序

源文件：[[main.cj]]

```cangjie
// 仓颉编程语言入门示例程序
// 功能：输出学校、姓名和学号
main(): Int64 {
    let school: String = "杭州电子科技大学"
    let name: String = "XXX"
    let stuId: String = "XXXXXXXX"

    println("我是来自" + school + "的" + name + "，学号是" + stuId)
    return 0
}
```

涉及的语法点：

| 语法 | 含义 |
| --- | --- |
| `main(): Int64 { … }` | 程序入口，返回值作为进程退出码；**不带** `func` 关键字 |
| `let name: String = "…"` | 不可变绑定，`名称: 类型 = 值`，类型标注可省略 |
| `"a" + b` | 字符串拼接，`+` 右侧可接 `String` 变量 |
| `println(…)` | 标准库内置的控制台输出函数，自动换行 |
| `//` | 单行注释 |
| `return 0` | 正常退出，返回 0 |

## 三、编译与运行

```powershell
# 编译：-o 指定输出文件名
cjc main.cj -o main.exe

# 运行（需 cangjie\runtime\lib\windows_x86_64_cjnative 在 PATH 中）
.\main.exe
```

目录下另附 [[run_demo.bat]]，双击即可自动完成「配置 PATH → 编译 → 运行」，便于本机复现。
